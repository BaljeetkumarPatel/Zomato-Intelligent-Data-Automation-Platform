to run model Stage file
     dbt run --select staging 


to run model mart file
    dbt run --select marts

to perform test run command in terminal
   dbt test

to run dbt model from start to end use this command
  dbt build

docker
   docker-compose build


to start prosgress server  
   docker-compose up -d


| Component          | Job                                             |
| ------------------ | ----------------------------------------------- |
| **Docker**         | Runs isolated environments/containers           |
| **Docker Compose** | Creates and connects all your containers        |
| **PostgreSQL**     | Stores Airflow metadata                         |
| **Airflow Init**   | Initializes DB + creates admin user             |
| **API Server**     | Airflow UI/API                                  |
| **Scheduler**      | Decides when tasks should run                   |
| **DAG Processor**  | Reads/parses DAG Python files                   |
| **DAG**            | Defines your pipeline                           |
| **dbt**            | Performs SQL-based transformations              |
| **Snowflake**      | Your data warehouse                             |
| **Volumes**        | Share/persist files between host and containers |
| **`.env`**         | Stores configuration/secrets                    |
